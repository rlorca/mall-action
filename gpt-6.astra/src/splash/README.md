# FLICKERSOFT ident
Import `splashFrame(frame)` at 60 Hz. Draw each returned letter when `visible`, using its palette `color`. Draw `underline` and `presents` when true. Play a jingle on `jingle`; advance when `done` or any input. No browser, renderer or game dependencies. Duration: 180 frames; alternating, out-of-phase letter flicker for the first 60.
